## Current Project

# Smart Manufacturing Team Productivity Prediction

Our current project focuses on predicting the actual productivity of garment manufacturing teams using operational and workforce-related data.

The project aims to understand how factors such as workforce size, overtime, incentives, idle time, style changes, and production targets are associated with team productivity.

---

## Project Objectives

- Predict actual team productivity using machine learning
- Analyze operational and workforce-related factors
- Identify the most influential variables
- Compare expected and actual productivity
- Build an interpretable and reliable regression model
- Support data-driven decision making in manufacturing environments

---

## Dataset

**Dataset:** Productivity Prediction of Garment Employees  
**Source:** UCI Machine Learning Repository  
**Records:** 1,197  
**Machine Learning Task:** Regression  
**Target Variable:** Actual Productivity
