## Current Project

### Smart Manufacturing Team Productivity Prediction

A machine learning project designed to predict the actual productivity of garment manufacturing teams using operational data.

The project analyzes factors such as:

- Number of workers
- Overtime
- Incentives
- Idle time
- Idle workers
- Style changes
- Targeted productivity
- Work in progress

---

## Project Goal

Our goal is to build a reliable machine learning regression model that can:

- Predict actual team productivity
- Identify factors associated with productivity
- Analyze operational patterns
- Support data-driven decision making
- Compare predicted and actual performance

---

## Dataset

**Dataset:** Productivity Prediction of Garment Employees  
**Source:** UCI Machine Learning Repository  
**Records:** 1,197  
**Task:** Regression  
**Target:** Actual Productivity
